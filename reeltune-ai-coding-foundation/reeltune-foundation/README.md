# ReelTune — AI Coding Foundation

This package contains the repo-level guardrails for building ReelTune with AI/vibe-coding tools.

## Included
- `AGENTS.md` — persistent coding rules/context
- `docs/PLAN.md` — ordered 30-60 minute tasks
- `docs/DATA_MODEL.md` — database entities and invariants
- `docs/API_CONTRACTS.md` — REST request/response contracts
- `docs/DESIGN_SYSTEM.md` — UI rules based on the approved visual direction
- `docs/TESTING.md` — test strategy and acceptance rules
- `docs/ENVIRONMENT.md` + `.env.example` — secrets/config baseline
- `docs/DEPLOYMENT.md` — deployment path
- `docs/LLM_APP_RULES.md` — rules if the product itself uses LLMs
- `docs/AI_WORKFLOW.md` — how to run each AI coding session
- `.gitignore` — secret/build protection

## Recommended first move
Copy these files into the root of your ReelTune repository. Then start with T001 and work through the plan one task at a time.
