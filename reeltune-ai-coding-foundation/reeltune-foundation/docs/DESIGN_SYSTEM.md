# ReelTune Design System

Inspired by the supplied Hubo-style visual direction without copying it.

## Visual language
Premium dark music app, warm neutral surfaces, restrained amber accent, minimal UI, Gen-Z but not noisy.

## Colors
- background #080706
- secondary #11100E
- card #181512
- elevated #211B16
- accent #D99A5B
- highlight #F0C28F
- primary text #F5F1EB
- secondary text #A9A29A
- muted #6F6A64
- success #8FBF9A
- error #D77A70

## Typography
Manrope preferred; Inter/Plus Jakarta Sans acceptable. Display 42, H1 32, H2 24, H3 18, body 15, small 13, caption 11.

## Navigation
Mobile: Home / Search / + Save / Library / Profile.

## Signature interaction
Save From Reel is the primary CTA. Use a subtle sound-pulse/waveform animation for recognition, never excessive motion.

## Components
Button, IconButton, SongCard, SongRow, AlbumArtwork, PlaylistCard, PlaylistHeader, SearchBar, BottomSheet, Modal, Toast, ProgressBar, ServiceButton, TabBar, EmptyState, LoadingState, AudioWave.

## Accessibility
Minimum touch target 44x44, visible focus states, semantic labels, reduced-motion support, sufficient contrast, dynamic text where platform allows.
